# RFM Analytics Lab v6

RFM Analytics Lab v6 is an interactive CRM analytics platform built using Python and Streamlit.

It demonstrates how organizations can analyze customer transaction data using Recency, Frequency and Monetary (RFM) metrics to derive marketing insights.

## Features

- Synthetic retail dataset generator
- RFM analysis
- Customer segmentation
- Machine learning clustering
- Customer lifetime value estimation
- Churn prediction
- Campaign simulation
- Marketing strategy recommendations

## Installation

Clone the repository

git clone https://github.com/YOUR_USERNAME/rfm-analytics-lab-v6.git

Install dependencies

pip install -r requirements.txt

Run the application

streamlit run app.py
